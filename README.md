# Movement Ecology of *Tremarctos ornatus* in the Ecuadorian Andes

This project was entirely developed in R and no new software was produced. Core packages to this work include [ctmm](https://ctmm-initiative.github.io/ctmm/) for continuous-time movement modeling, [momentuHMM](https://github.com/bmcclintock/momentuHMM) for movement behavior analysis using Hidden Markov Models, and [Diel.Niche](https://github.com/diel-project/Diel-Niche-Modeling) to evaluate diel phenotypes under bayesian frameworks.

# Data and Code Availability

GPS and VHF fixes used in this study **will be** freely available upon publication at [Movebank](https://www.movebank.org/cms/webapp?gwt_fragment=page%3Dstudies%2Cpath%3Dstudy1403649299) with license CC BY-NC, under the name "Rethinking the Movement Ecology of Andean Bears: Temperature-Driven Cath-
emerality and Seasonal Space-Use Cycle" (Movebank ID: 1403649299).

Code will be available upon publication.
